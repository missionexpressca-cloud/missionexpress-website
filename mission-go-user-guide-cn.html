Mission Go 司机端使用说明

本说明适用于 Mission Go 司机端 App。司机账号需审核通过后，才能上线接收配送任务。

一、App 用途

Mission Go 是配送司机和合作伙伴使用的任务 App，用于接收本地配送、同城取件、大件取件、包裹任务、仓库派送和路线配送任务。

  • 查看可接任务和已接任务
  • 管理上线 / 下线状态
  • 接收派单邀请并确认任务
  • 使用导航前往取件地和送达地
  • 拍照确认取件、送达和异常情况
  • 查看任务状态和历史记录

二、登录与账号审核

  1. 下载并安装 Mission Go App。
  2. 使用注册手机号或账号登录。
  3. 首次使用前，请按要求完成司机资料、车辆资料和必要文件提交。
  4. 账号审核通过后，才可以上线接单。
如果登录后看不到接单功能，通常是账号尚未审核通过，或当前城市/模块暂未为该账号开通。

三、上线接单

  1. 进入首页后，根据需要开启对应模块的 Online 状态。
  2. 上线后，系统会根据订单类型、位置、服务区域和任务规则推送可接任务。
  3. 收到任务邀请后，请在倒计时内查看订单信息并决定是否接受。
  4. 接受任务后，请按 App 内显示的流程完成取件和送达。

四、主要任务类型

1. Direct Pickup / 同城取件

适用于本地小件、餐食、商家订单或普通同城配送任务。司机接受任务后，按地址前往取件，再送达指定目的地。

2. Cargo Pickup / 大件取件

适用于较大、较重或需要额外确认的物品。请在取件和送达时仔细核对物品信息，并按要求上传照片。

3. Ship Parcel / 包裹任务

适用于包裹取件、转运或相关配送任务。此类任务可能允许连续接单，具体以 App 显示规则为准。

4. Warehouse Delivery / 仓库派送

适用于从仓库、站点或分拨点出发的路线派送任务。请按系统路线和包裹顺序完成配送。

五、取件与送达确认

  1. 到达取件地后，点击到达或确认取件。
  2. 按要求拍摄取件照片、包裹照片或交接证明。
  3. 送达时再次按要求拍摄送达照片或获取签收证明。
  4. 如果定位距离校验失败，但你确认已经到达现场，请按页面提示继续拍照并保留证明。

六、导航与定位

  • App 可打开地图导航前往取件地或送达地。
  • 请确认手机定位权限已开启。
  • 如果 GPS 漂移或定位不准，请在安全位置重新打开定位，必要时上传清晰照片作为现场证明。

七、异常处理

  • 联系不上客户、地址不清楚、无法进入建筑物、包裹异常或发生延误时，请及时联系平台支持。
  • 不要私自取消、丢弃、转交或改变包裹处理方式。
  • 涉及高价值、破损、丢失或客户争议的情况，请保留照片、聊天记录和现场说明。

八、安全提醒

  • Mission Go 是配送任务 App，不是载客服务。
  • 请遵守当地交通法规，安全驾驶。
  • 不要在驾驶过程中操作手机；请停车后再查看订单或拍照。
  • 请保护客户隐私，不要泄露客户地址、电话和订单信息。
