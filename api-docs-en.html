Overview

This document converts the source API file into a cleaner web page for publishing. All interfaces use HTTP POST unless noted otherwise. Request and response payloads use UTF-8 encoded JSON, except for the PDF display endpoint.

Production Base URL
https://me.missionexpress.ca/api/post/out
Request Header

Parameter names and endpoint names are kept exactly as they appear in the source file. English labels and descriptions have been polished for web presentation.

Authentication & Signature

The platform provides app_key and app_secret. The business request object must be converted to a JSON string and passed through the data field.

Signature rule:

sign = SHA256(request_json + "app_secret=" + app_secret)

PHP example:

private function createSign(string $request_str, string $key) {
    return hash("sha256", $request_str . "app_secret=" . $key);
}

Common Request Fields

FieldRequiredTypeDescription
app_keyYesstringApp key issued by the platform
signYesstringSignature value
dataYesstringJSON string of business parameters

Standard Response

A successful request returns code = 1. Any other value indicates an error.

{
  "code": 1,
  "msg": "ok",
  "time": "1690796144",
  "data": {
    "orderNo": "491d930ef328d4ec142233c82cc28816",
    "time": 1690796144
  }
}

Error Codes

CodeMeaning
1001Missing required parameter: sign
1003Failed to parse request data
1004Missing required parameter: app_key
1005app_key does not exist
1006Signature verification failed
0General error
